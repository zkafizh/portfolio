## 🛠 Tech Stack
- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, Grid/Flexbox, animations, dark/light mode
- **Vanilla JS** — Mobile menu, scroll spy, reveal animations, form handling, back-to-top
- **Fonts** — Space Grotesk (display), JetBrains Mono (mono)
- **No frameworks, no build step** — Single-file deployment

## ✨ Design Philosophy
Built with **antislop** principles:
- No fake stats, testimonials, or placeholder content
- Real data only from actual resume
- WCAG AA contrast, keyboard navigation, reduced motion support
- Automatic dark/light mode via `prefers-color-scheme`
- Mobile-first responsive (320px+)
- ENERGY 3 / RHYTHM 2 / MOTION 2 — bold, expressive, deliberate
